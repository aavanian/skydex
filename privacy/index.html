Skydex Privacy and data flow

Account profile Follows scan Settings

In short

Skydex has no server of its own and collects nothing. Your browser downloads the app once, then does all the work itself: it fetches public Bluesky data directly from Bluesky's services and analyses it on your device. Nothing you look up is sent to the author of Skydex.

Who sees what

skydex.avanian.net (hosted on Cloudflare)
Serves the app's files. Like any website, Cloudflare logs requests (IP address, browser, pages requested) under its own policy. Skydex sets no cookies and runs no analytics or tracking script.
Bluesky's public services
To analyse an account, your browser asks Bluesky's public API (public.api.bsky.app), the identity directory (plc.directory) and the account's data server (for accounts hosted by Bluesky, a *.host.bsky.network server) for public data: profile, posts, reposts, follows and block records. These services see your IP address and which accounts you look up, as they would with any Bluesky app. No login is involved.
OpenRouter, only for content tags
Content tags are optional and only run when you click Classify. Your browser then sends the text of the analysed account's own posts (and of the posts they quote) to OpenRouter with your API key, one request per post. OpenRouter passes them to the model's provider (for example Cloudflare for Clef Flash). Their policies apply: OpenRouter privacy. The key is sent only to openrouter.ai. Logging in with OpenRouter happens on openrouter.ai, which hands the page a key; Skydex never sees your OpenRouter password.
Bluesky login, only to unfollow
Unfollowing from the follows scan needs you to log in to Bluesky in a popup run by your account's own login server (for most accounts, bsky.social). Skydex asks only for permission to delete follow records: it cannot post, follow, like, read private data or change your profile. Your password goes to that login server only. While logging in, the login server fetches Skydex's public description (client-metadata.json) from this site.

What stays in your browser

Cache (IndexedDB)
Public histories of the last 20 accounts downloaded, and for the follows scan, the type and time of each followed account's latest activities. This makes revisits fast. Clear it from Settings.
Local storage
Your settings, the account you last scanned, content tags already computed (so you never pay twice for the same post), and your OpenRouter key only if you ticked Remember the key.
Session storage (cleared when the tab closes)
Your OpenRouter key by default, and the state of an OpenRouter login in progress.
Page memory only
The Bluesky login. It is never saved: closing or reloading the tab ends it, and Log out also revokes it on Bluesky's side.

Anything running in the page could read these (typically browser extensions allowed to read and change data on all websites), so Skydex only runs its own code (enforced by a Content-Security-Policy) and cannot be embedded by other sites. Give your OpenRouter key a small credit limit.

Removing it all

Clear cached data in Settings removes downloaded histories, follows scan data and content tags. To also remove your settings, the last scanned account and a remembered OpenRouter key, clear this site's data in your browser:

  • Firefox: click the padlock in the address bar, then Clear cookies and site data…
  • Chrome, Edge and other Chromium browsers: click the icon left of the address, then Site settings → Delete data.
  • Safari: Settings → Privacy → Manage Website Data…, search for skydex.avanian.net and remove it.

Closing the tab already forgets a key that was not remembered and any Bluesky login.
